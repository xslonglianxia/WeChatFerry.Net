# WeChatFerry.Net 使用指南

## 一、环境准备

### 1.1 系统要求

- **操作系统**: Windows 10/11 或 Windows Server
- **.NET 框架**: .NET 6.0 或 .NET 8.0
- **微信客户端**: 必须安装特定版本（与 WCF SDK 版本匹配）
- **开发工具**: Visual Studio 2022 或 VS Code + C# 扩展

### 1.2 微信版本要求

当前支持的微信版本：
- **v39.4.2**: 支持微信 3.9.12.17
- **v39.4.3**: 最新版本

可以在 [WeChatFerry releases](https://github.com/lich0821/WeChatFerry/releases) 下载对应版本的微信。

## 二、安装步骤

### 2.1 通过 NuGet 安装

```bash
dotnet add package WeChatFerry.Net
```

### 2.2 或者克隆源码

```bash
git clone https://github.com/SilkageNet/WeChatFerry.Net.git
cd WeChatFerry.Net
dotnet build
```

### 2.3 运行示例

```bash
cd WeChatFerry.Net.Example
dotnet run
```

## 三、快速开始

### 3.1 最简单的示例

```csharp
using WeChatFerry.Net;

// 创建客户端
using var client = new WCFClient();

// 订阅消息事件
client.OnRecvMsg += (sender, msg) =>
{
    Console.WriteLine($"收到消息: [{msg.Type}] {msg.Sender}: {msg.Content}");
};

// 启动客户端
if (!await client.Start())
{
    Console.WriteLine("启动失败！");
    return;
}

Console.WriteLine("机器人已启动，按任意键退出...");
Console.ReadKey();
```

### 3.2 完整的快速开始代码

```csharp
using WeChatFerry.Net;

class Program
{
    static async Task Main(string[] args)
    {
        // 1. 创建客户端（可选：自定义配置）
        var options = new WCFClientOptions
        {
            Port = 6666,                      // RPC 端口
            MessageInterval = 2000,           // 消息间隔（毫秒）
            MessageLimitInMinutes = 6,        // 每分钟消息数限制
            DisableWeChatUpgrade = true,      // 禁用微信自动更新
            Logger = new ConsoleLogger()      // 使用控制台日志
        };

        using var client = new WCFClient(options);

        // 2. 订阅消息事件
        client.OnRecvMsg += OnMessageReceived;

        // 3. 启动客户端
        Console.WriteLine("正在启动机器人...");
        if (!await client.Start(timeout: 60))
        {
            Console.WriteLine("启动失败！请确保：");
            Console.WriteLine("1. 微信已登录");
            Console.WriteLine("2. WeChatFerry 插件已加载");
            return;
        }

        // 4. 获取并显示自己的信息
        var selfWxid = await client.RPCGetSelfWxidAsync();
        Console.WriteLine($"机器人已就绪，微信ID: {selfWxid}");

        // 5. 发送一条测试消息到文件传输助手
        client.SendTxt("filehelper", "机器人已启动！");
        Console.WriteLine("已发送测试消息到 filehelper");

        // 6. 保持运行
        Console.WriteLine("按 Q 键退出...");
        while (Console.ReadKey().Key != ConsoleKey.Q)
        {
            Thread.Sleep(100);
        }
    }

    static void OnMessageReceived(object? sender, Message msg)
    {
        // 过滤自己发送的消息（避免回复循环）
        if (msg.IsSelf) return;

        Console.WriteLine($"[{msg.Time:HH:mm:ss}] {msg.Sender}: {msg.Content}");

        // 自动回复示例
        if (msg.Type == MessageType.Text && msg.Content.Contains("你好"))
        {
            client.SendTxt(msg.Sender, "你好！有什么可以帮助你的吗？");
        }
    }
}
```

### 4.2 接收消息处理

#### 4.2.1 基础消息接收

```csharp
client.OnRecvMsg += (sender, msg) =>
{
    Console.WriteLine($"消息ID: {msg.ID}");
    Console.WriteLine($"消息类型: {msg.Type}");
    Console.WriteLine($"发送者: {msg.Sender}");
    Console.WriteLine($"内容: {msg.Content}");
    Console.WriteLine($"时间: {msg.Time}");
    Console.WriteLine($"是否群消息: {msg.IsGroup}");
    if (msg.IsGroup)
    {
        Console.WriteLine($"群ID: {msg.RoomID}");
    }
};
```

#### 4.2.2 处理不同类型的消息

```csharp
client.OnRecvMsg += (sender, msg) =>
{
    switch (msg.Type)
    {
        case MessageType.Text:
            Console.WriteLine($"文本消息: {msg.Content}");
            break;

        case MessageType.Image:
            Console.WriteLine("收到图片");
            // 下载图片
            DownloadImage(msg);
            break;

        case MessageType.Voice:
            Console.WriteLine("收到语音消息");
            break;

        case MessageType.FileOrLink:
            Console.WriteLine($"文件/链接: {msg.Content}");
            // 下载文件
            DownloadFile(msg);
            break;

        case MessageType.Video:
            Console.WriteLine("收到视频");
            break;

        case MessageType.BusinessCard:
            Console.WriteLine("收到名片");
            break;

        case MessageType.Location:
            Console.WriteLine($"位置: {msg.Content}");
            break;

        case MessageType.ContactConfirm:
            Console.WriteLine("收到好友验证请求");
            // 处理好友请求
            client.AcceptFriend(msg.Content);
            break;

        case MessageType.Pat:
            Console.WriteLine($"有人在群里拍了拍: {msg.Sender}");
            break;

        case MessageType.RedPacket:
            Console.WriteLine("收到红包");
            break;

        case MessageType.Recall:
            Console.WriteLine($"消息被撤回: {msg.Content}");
            break;

        case MessageType.System:
            Console.WriteLine($"系统消息: {msg.Content}");
            break;
    }
};
```

## 五、进阶用法

### 5.1 自定义日志记录

```csharp
public class MyLogger : ILogger
{
    private readonly string _logFile;
    private readonly object _lock = new();

    public MyLogger(string logFile = "robot.log")
    {
        _logFile = logFile;
    }

    public void Debug(string messageFormat, params object[] @params)
        => Log("DEBUG", messageFormat, @params);

    public void Info(string messageFormat, params object[] @params)
        => Log("INFO", messageFormat, @params);

    public void Warn(string messageFormat, params object[] @params)
        => Log("WARN", messageFormat, @params);

    public void Error(string messageFormat, params object[] @params)
        => Log("ERROR", messageFormat, @params);

    public void Fatal(string messageFormat, params object[] @params)
        => Log("FATAL", messageFormat, @params);

    private void Log(string level, string messageFormat, params object[] @params)
    {
        var message = $"{DateTime.Now:yyyy-MM-dd HH:mm:ss} [{level}] {string.Format(messageFormat, @params)}";
        lock (_lock)
        {
            File.AppendAllText(_logFile, message + Environment.NewLine);
        }
        Console.WriteLine(message);
    }
}

// 使用自定义日志
var options = new WCFClientOptions
{
    Logger = new MyLogger("wechat_robot.log")
};
using var client = new WCFClient(options);
```

### 5.3 后台服务模式

```csharp
public class WeChatBotService : BackgroundService
{
    private readonly WCFClient _client;

    public WeChatBotService()
    {
        _client = new WCFClient();
        _client.OnRecvMsg += OnMessageReceived;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        await _client.Start();
        
        while (!stoppingToken.IsCancellationRequested)
        {
            await Task.Delay(1000, stoppingToken);
        }
    }

    public override async Task StopAsync(CancellationToken cancellationToken)
    {
        _client.Dispose();
        await base.StopAsync(cancellationToken);
    }

    private void OnMessageReceived(object? sender, Message msg)
    {
        // 处理消息
    }
}
```

### 5.4 消息频率控制

SDK 内置了消息发送频率控制：

```csharp
var options = new WCFClientOptions
{
    MessageInterval = 2000,           // 基础发送间隔（毫秒）
    MessageLimitInMinutes = 6,       // 每分钟最多发送的消息数
    RPCTimeout = 10000               // RPC 超时时间（毫秒）
};
```

发送流程：
1. 调用 `SendTxt()` 等方法 → 消息进入队列
2. 后台任务 `LoopSend` 循环处理队列
3. 检查频率限制（每分钟不超过 N 条）
4. 满足条件后发送消息

**注意**：不要修改这些值为过小的数字，否则可能导致账号被封！

## 六、常见问题

### 6.1 启动失败

**问题**: `Start()` 返回 false

**可能原因和解决方案**：
1. 微信未登录 → 先手动登录微信
2. WeChatFerry 插件未加载 → 确保 WCF 服务正在运行
3. 端口被占用 → 修改 `Port` 配置
4. SDK 版本不匹配 → 更新到匹配的 SDK 版本

### 6.2 收不到消息

**检查项**：
1. 是否调用了 `RPCEnableRecvTxt()`
2. 日志是否有错误
3. 防火墙是否阻止了连接
4. 微信是否已登录

### 6.3 发送消息失败

**可能原因**：
1. 接收者 ID 不正确
2. 文件路径不存在
3. 超过了发送频率限制
4. 网络问题

### 6.4 SDK 找不到

**解决方案**：
1. 确保 wcf 目录下有对应版本的 SDK 文件
2. 手动指定 `SDKPath`
3. 检查微信版本是否与 SDK 匹配

## 七、最佳实践

### 7.1 安全建议

1. **不要修改频率限制** → 可能导致封号
2. **定期备份数据** → 微信数据可能损坏
3. **使用专用账号** → 建议使用小号进行测试
4. **遵守微信协议** → 不要进行违规操作

### 7.2 性能优化

1. **消息处理异步化** → 不要在事件处理中做耗时操作
2. **合理使用缓存** → 联系人列表会被缓存
3. **数据库查询优化** → 避免频繁全表扫描

### 7.3 错误处理

```csharp
try
{
    var ok = await client.RPCSendTxtAsync("wxid_xxxxx", "Hello");
    if (!ok)
    {
        Console.WriteLine("发送失败");
    }
}
catch (Exception ex)
{
    Console.WriteLine($"发生错误: {ex.Message}");
}
```
